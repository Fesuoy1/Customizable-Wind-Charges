## Want more control over wind charges?
This mod adds a few gamerules that make wind charges more useful/customizable.

## Gamerules Implemented
- /gamerule customizable_wind_charges:wind_charge_cooldown [number, defaulted to 10]
- /gamerule customizable_wind_charges:wind_charge_power [number, defaulted to 1]
- /gamerule customizable_wind_charges:wind_charge_knockback [number, defaulted to 1]
- /gamerule customizable_wind_charges:breeze_wind_charge_power [number, defaulted to 3]
- /gamerule customizable_wind_charges:breeze_wind_charge_knockback [number, defaulted to 1]
